# UI glossary: Tiếng Việt / English

The custom Herdr UI has two languages, switched by shared state `lang` (`"vi"`, the default, or
`"en"`) from the VI | EN pill at the bottom of the sidebar. Every user-visible string is written
in both, at the place it's used: `L("Phiên mới", "New session")`. Use these words so the same
thing reads the same everywhere. English is sentence case; Vietnamese keeps the "bạn" voice the
UI already uses for the person ("Chờ bạn duyệt", "cần bạn trả lời").

## Not translated

- Text sent to agents (briefs, prompts in actions, messages to the coordinator, `hc send` text,
  a tab's first task): stays Vietnamese.
- Program and product names: Claude Code, Codex, Antigravity, Herdr, Opus, Sonnet, Haiku, Fable,
  Gemini, Git, PR, MCP. Effort values: low, medium, high, xhigh, max.
- Keys (Ctrl+Shift+N), paths, branch names, ids (T-12, t4b), file names.
